族谱系统操作帮助说明

按顺序完成「字辈分支 → 家族人员 → 祖训家规」三大步骤，即可快速建立规范、完整的家族谱系。

整体操作顺序

使用本系统录入家族信息，请按照顺序操作：

1
设置家族字辈分支
录入辈分用字与房系分支，作为后续添加成员的基础资料。
2
添加家族人员
选择字辈、分支，逐条录入家族成员并绑定父辈关系。
3
设置家族祖训家规
录入祖训标题、正文、出处，并决定是否在首页展示。
重要提醒 字辈与分支是基础资料，新增家族成员时需要直接选用已经建好的字辈、分支。如果没有提前设置，新增人员无法正常填写辈分和房系信息。

一家族字辈与分支设置

本功能用来录入家族世代辈分用字、各个家族房系分支。后续添加家人的时候，直接在这里选择已经录入好的内容，保证整个家族辈分、房系统一规范。

1. 字辈

家族每一代人名字中间固定使用的汉字，比如 “钦”“遵”“道”“德”，代表一代人的辈分。建议按照辈分从老到少依次录入，先录入祖辈，再录入父辈，接着录入子辈、孙辈。

2. 分支

家族内部的房系划分，用来区分不同支派，例如嫡系、长房支、二房支、旁系分支。同一个家族可以建立多个不同分支。

注意 新增家族成员时，辈分、分支只能选择这里已经保存好的内容，不能随意填写自定义文字。

二添加家族人员

前置要求 必须已经完成【家族字辈与分支设置】。新增家人需要选择对应的字辈与分支。

新增家人有两种绑定父亲的方式，推荐优先使用用户 ID 关联。

1. 关联父辈方式一：用户 ID 关联（推荐）

选择该方式后，直接选择系统中已经录入好的父亲信息，系统自动读取父亲编号完成关系绑定，不需要手动填写父亲姓名。

2. 关联父辈方式二：身份证号关联

选择该方式，填写父亲的身份证号码来匹配父辈，同时需要手动填写父亲真实姓名。

需要填写的人员信息说明

  1. 真实姓名：填写该家族成员的完整真实名字。
  2. 性别：选择男或者女。
  3. 身份证号码：填写成员身份证，用于辅助推算传统干支生辰。
  4. 公历生日：选择公历的出生年月日。只需要填写公历日期，系统会自动换算出传统干支生辰；如果自动换算结果不符合实际，也可以手动修改干支生辰。
  5. 干支生辰：传统农历干支纪年记录出生时间，例如 “丙午年 丙申月 戊午日 丙辰时”。可以由公历生日自动生成，也支持自己手动输入修改。
  6. 身份称谓：选定父亲之后，选择该子女在家中的身份，可选：嫡长子、嫡次子、嫡三子、庶长子、庶次子、庶三子、嫡长女、嫡次女、嫡三女、庶长女、庶次女、庶三女。
  7. 字辈：从前面已经设置好的字辈列表当中，选择此人所属辈分用字，父子两代辈分不能相同。
  8. 分支：从前面已经设置好的分支列表当中，选择该成员归属的家族房系分支。
填写小提示
  • 字辈要符合家族世代逻辑，父亲和子女不能使用同一套字辈。
  • 身份称谓根据父辈正庶地位、子女排行来选择，如实记录家族关系。

三家族祖训家规设置

录入家族人员完成后，可以录入本家族的祖训、家训、家规内容。可以保存多条祖训。

  1. 祖训标题：填写家训的标题，例如《白氏祖训总纲》《居家修身训》，会在祖训列表页面展示。
  2. 祖训正文：填写祖训、家规完整文字内容，可以录入大段文字。
  3. 出处来源：记录这份祖训来自哪里，例如祠堂碑刻、旧族谱摘抄、后世族老整理编撰。
  4. 是否在家族首页展示
    • 开启：这条祖训会直接显示在家族首页，供所有人查看，适合家族总纲类重要祖训。
    • 关闭：仅在祖训专门页面可以查看，不会出现在家族首页，适合存档备用、次要家训。

✓完整操作流程总结

1
第一步：维护家族基础信息
录入家族所有字辈、各个分支房系。
2
第二步：新增家族人员
  1. 选择绑定父亲的方式，关联到家族内已有的父辈；
  2. 填写姓名、性别、身份证、公历生日；
  3. 系统自动生成干支生辰，如有需要手动调整；
  4. 选择身份称谓，选择对应字辈、所属分支，保存完成人员新增。
3
第三步：录入家族祖训
填写标题、正文、出处，选择是否在首页展示，保存祖训。
补充提示 如果需要修改字辈、人员信息、祖训内容，可以进入对应页面找到记录进行编辑修改；不再使用的内容可以做归档隐藏。
